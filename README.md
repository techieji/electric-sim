UI keybindings:
 - Non-repeatable: only triggers when pressed the first time
   - "s": enables select mode
   - Escape: restores sane defaults: disables select and resets the stroke style
   - "q" and "w": increases and decreases the stroke size for the default stroke (temporary)
   - "y": yanks the selected section into the clipboard
   - "p": lets you paste a previously copied section
 - Repeatable: triggers continuously while held
   - Arrow keys: navigation
   - "l" and "k": zoom in and out (temporary)
